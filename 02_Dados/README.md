 🗂️ Atividade 02 — Dados Abertos da PRF

Atividade prática desenvolvida durante o curso de **Análise de Dados da Aponti**, utilizando dados abertos de acidentes de trânsito disponibilizados pela **Polícia Rodoviária Federal (PRF)**.



🎯 Objetivo

Trabalhar com um conjunto de dados real, compreendendo sua estrutura e realizando procedimentos de organização e preparação necessários para utilização em análises de dados.

A atividade teve como foco desenvolver a capacidade de lidar com dados brutos, identificar suas características e preparar as informações para etapas posteriores de análise.



 📌 Contexto

Os dados utilizados são provenientes da base de **acidentes de trânsito em rodovias federais brasileiras**, disponibilizada pela Polícia Rodoviária Federal.

O conjunto apresenta diferentes informações relacionadas às ocorrências, permitindo análises envolvendo aspectos temporais, geográficos, circunstanciais e relacionados à gravidade dos acidentes.



 📊 Estrutura dos dados

A base utilizada reúne informações relacionadas a diferentes aspectos dos acidentes, incluindo:

- identificação da ocorrência;
- data e horário;
- unidade federativa;
- rodovia;
- município;
- causa do acidente;
- tipo de acidente;
- classificação da ocorrência;
- condições meteorológicas;
- características da pista;
- traçado da via;
- quantidade de pessoas envolvidas;
- mortos e feridos;
- quantidade de veículos;
- localização geográfica.



 🔎 Atividades realizadas

Durante o desenvolvimento da atividade foram trabalhados conceitos relacionados à organização e análise de dados, incluindo:

 📥 Importação dos dados

Utilização de uma base real para aplicação prática dos conhecimentos desenvolvidos durante o curso.

 🔍 Exploração inicial

Análise da estrutura do conjunto de dados e identificação das principais variáveis disponíveis.

 🧹 Preparação dos dados

Organização das informações para facilitar sua utilização nas etapas de análise.

Foram considerados aspectos como:

- tipos de dados;
- valores ausentes;
- consistência das informações;
- organização das colunas;
- identificação das variáveis relevantes.

 📈 Preparação para análise

A organização da base permitiu que os dados fossem utilizados posteriormente em análises exploratórias, agregações e construção de indicadores.



 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Google Drive
- Dados abertos da PRF



💡 Principais aprendizados

A atividade contribuiu para o desenvolvimento de conhecimentos fundamentais relacionados ao trabalho com dados reais.

Entre os principais aprendizados estão:

- compreender a estrutura de uma base de dados;
- identificar diferentes tipos de variáveis;
- organizar dados para análise;
- reconhecer problemas de qualidade;
- compreender a importância da preparação dos dados;
- utilizar ferramentas de planilha no processo de análise;
- transformar dados brutos em informações mais adequadas para exploração.
