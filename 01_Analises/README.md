 📊 Atividade 01 — Análise de Dados da PRF 2025

Projeto de análise e preparação de dados desenvolvido durante o curso de **Análise de Dados da Aponti**, utilizando dados abertos de acidentes de trânsito em rodovias federais disponibilizados pela **Polícia Rodoviária Federal (PRF)**.



 🎯 Objetivo

Realizar uma análise estruturada dos registros de acidentes de trânsito da PRF, aplicando técnicas de preparação, tratamento, exploração e transformação de dados.

O objetivo principal foi transformar os dados brutos em uma base organizada e adequada para análises posteriores, identificando padrões, indicadores e características relacionadas aos acidentes registrados em 2025.



 📌 Contexto

Os dados utilizados representam registros de acidentes ocorridos em rodovias federais brasileiras durante o período analisado.

A atividade foi desenvolvida como parte prática da formação em Análise de Dados, permitindo aplicar conceitos estudados ao longo do curso em um conjunto de dados real.



 🛠️ Tecnologias e ferramentas

- Python

- Matplotlib
- Jupyter Notebook



 🔎 Etapas da análise

O desenvolvimento da atividade envolveu diferentes etapas do processo de análise de dados:

 1. Carregamento dos dados

Importação do conjunto de dados disponibilizado pela PRF e verificação inicial de sua estrutura.

 2. Diagnóstico dos dados

Avaliação de:

- quantidade de registros;
- quantidade de colunas;
- tipos de dados;
- valores ausentes;
- consistência das informações;
- distribuição das variáveis.

 3. Tratamento e preparação

Foram realizadas etapas de preparação dos dados para permitir análises mais confiáveis, incluindo ajustes de tipos, tratamento de valores ausentes e organização das variáveis.

 4. Criação de variáveis

Foram utilizadas variáveis derivadas para facilitar a análise temporal e geográfica dos acidentes, permitindo uma exploração mais estruturada do conjunto de dados.

5. Exploração dos dados

A análise buscou identificar padrões relacionados a fatores como:

- localização dos acidentes;
- período e horário das ocorrências;
- condições meteorológicas;
- características das rodovias;
- causas dos acidentes;
- classificação e gravidade das ocorrências.



 📈 Indicadores analisados

Entre os principais indicadores trabalhados estão:

- quantidade total de acidentes;
- acidentes fatais;
- quantidade de mortos;
- quantidade de feridos;
- distribuição dos acidentes por localização;
- distribuição temporal das ocorrências;
- causas dos acidentes;
- condições meteorológicas;
- tipos de acidentes.
